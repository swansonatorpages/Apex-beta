# Apex Foundation Beta

A mobile-first daily foundation tracker for iPhone Safari and GitHub Pages.

Open in Safari and use Share > Add to Home Screen. Records stay in local browser storage. Export a JSON backup before switching devices or browsers. Fund contributions are manually confirmed; this app does not transfer money.

Run `node foundation-check.cjs` to check core rules. No dependencies or build step required.

In repository Settings > Pages, select GitHub Actions as source if not already enabled.
